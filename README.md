I design and build AI systems that take repetitive work off people's plates: voice agents that answer the phone, chatbots that sell, custom software, automations that connect everything, and pipelines that bring in leads. Built for production and measured by results.

## What I build

- 🤖 **AI agents & chatbots.** Voice agents that answer, triage and book appointments. WhatsApp assistants. Website chatbots grounded in live product catalogues, so they never invent a price or a product.
- 🧩 **Custom software.** Web apps and internal tools built to order, with authentication, roles, row-level security and automated tests. Mobile apps with React Native.
- ⚙️ **Automation & integrations.** n8n workflows that connect CRMs, calendars, e-commerce platforms, databases and LLMs, removing manual work between systems.
- 📈 **Marketing & lead generation.** Lead capture on web, voice and WhatsApp feeding a single pipeline, prospect research and scoring, and conversion-focused websites.
- 📊 **Data & dashboards.** BI dashboards that show what is really happening: calls, bookings, conversion and service quality.

## How I work

- **Production first.** Real users and real clients. Every project ships with handover documentation so it keeps running.
- **Measured, not assumed.** Explicit ground truth and honest limits. See the public evaluation below.
- **Secure by default.** No secrets in code, row-level security on every table, least-privilege keys.
